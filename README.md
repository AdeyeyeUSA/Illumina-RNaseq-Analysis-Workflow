The set of codes here work for quality check and data processing for illumina bulk sequencing data. The codes for downloading genome works in terminal like power shell. 
This code assumes that you have all the neccesary packages like salmon and fastqc installed.
Differential gene expression can also be performed with this codes but those works in R. For ease of use, you can run those codes in R studio. An assumption here is you have the packages for the loaded libraries in the code installed, if not simply install them with package.install command.
